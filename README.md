# Expense Tracker

A beginner-friendly Python expense tracker that helps users track their expenses.

## Features

* **Add Expense:** Allows users to enter their expenses according to a category.
* **View Expenses:** Allows users to view all the entered expenses.
* **Total Spending:** Provides the user with the total amount spent.
* **Category Summary:** Helps users view the amount spent category-wise.
* **Exit:** Allows users to exit the program and terminate its execution.

## Technologies Used

* Python
* Visual Studio Code

## How to Run

1. Open the project in Visual Studio Code.
2. Open **Terminal → New Terminal**.
3. Run the program using:

```bash
python expense_tracker.py
```

4. Choose an option from the menu:

```text
1 → Add Expense
2 → View Expenses
3 → Total Spending
4 → Category Summary
5 → Exit
```
